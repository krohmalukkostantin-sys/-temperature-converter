# Конвертер температур

## Короткий опис

Конвертер температур — це невелика програма на Python, яка дозволяє конвертувати температуру між різними одиницями вимірювання: Цельсієм, Фаренгейтом і Кельвіном. Програма використовує функції для виконання математичних розрахунків та надає користувачу можливість обрати необхідну операцію через текстове меню.

## Функціональність

- Конвертація Цельсія у Фаренгейт.
- Конвертація Фаренгейта у Цельсій.
- Конвертація Цельсія у Кельвін.
- Конвертація Кельвіна у Цельсій.
- Конвертація Фаренгейта у Кельвін.
- Введення температури користувачем.
- Виведення результату конвертації з точністю до двох знаків після коми.

## Інструкції з встановлення

1. Переконайтеся, що на комп'ютері встановлено Python.
2. Клонуйте репозиторій за допомогою Git.
3. Перейдіть до папки проєкту.
4. Запустіть програму командою:

   `python main.py`

## Приклад використання

Після запуску програми користувач побачить меню конвертації:

```text
=== Конвертер температур ===
1. Цельсій -> Фаренгейт
2. Фаренгейт -> Цельсій
3. Цельсій -> Кельвін
4. Кельвін -> Цельсій
```

Наприклад, користувач обирає конвертацію Цельсія у Фаренгейт, вводить температуру 25, і програма виводить результат:

```text
Виберіть операцію (1-4): 1
Введіть температуру: 25
25.0°C = 77.00°F
```

|:----------------------|:------------:|:----------------:|-------------------------:|
| celsius_to_fahrenheit | celsius      | (C × 9/5) + 32   | Цельсій → Фаренгейт      |
| fahrenheit_to_celsius | fahrenheit   | (F − 32) × 5/9   | Фаренгейт → Цельсій      |
| celsius_to_kelvin     | celsius      | C + 273.15       | Цельсій → Кельвін        |
| kelvin_to_celsius     | kelvin       | K − 273.15       | Кельвін → Цельсій        |
| fahrenheit_to_kelvin  | fahrenheit   | через Цельсій    | Фаренгейт → Кельвін      |
