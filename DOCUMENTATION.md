
# Документація функцій

## `celsius_to_fahrenheit(celsius)`

- **Опис:** Функція конвертує температуру з градусів Цельсія у градуси Фаренгейта за відповідною математичною формулою.
- **Параметри:** `celsius` — температура у градусах Цельсія (числове значення).
- **Що повертає:** Числове значення температури у градусах Фаренгейта.
- **Приклад використання:**

  ```python
  result = celsius_to_fahrenheit(25)
  print(result)  # 77.0
  ```

## `fahrenheit_to_celsius(fahrenheit)`

- **Опис:** Функція конвертує температуру з градусів Фаренгейта у градуси Цельсія.
- **Параметри:** `fahrenheit` — температура у градусах Фаренгейта (числове значення).
- **Що повертає:** Числове значення температури у градусах Цельсія.
- **Приклад використання:**

  ```python
  result = fahrenheit_to_celsius(77)
  print(result)  # 25.0
  ```

## `celsius_to_kelvin(celsius)`

- **Опис:** Функція конвертує температуру з градусів Цельсія у Кельвіни.
- **Параметри:** `celsius` — температура у градусах Цельсія (числове значення).
- **Що повертає:** Числове значення температури у Кельвінах.
- **Приклад використання:**

  ```python
  result = celsius_to_kelvin(25)
  print(result)  # 298.15
  ```

## `kelvin_to_celsius(kelvin)`

- **Опис:** Функція конвертує температуру з Кельвінів у градуси Цельсія.
- **Параметри:** `kelvin` — температура у Кельвінах (числове значення).
- **Що повертає:** Числове значення температури у градусах Цельсія.
- **Приклад використання:**

  ```python
  result = kelvin_to_celsius(298.15)
  print(result)  # 25.0
  ```

## `fahrenheit_to_kelvin(fahrenheit)`

- **Опис:** Функція конвертує температуру з градусів Фаренгейта у Кельвіни, використовуючи функції конвертації Фаренгейта у Цельсій та Цельсія у Кельвін.
- **Параметри:** `fahrenheit` — температура у градусах Фаренгейта (числове значення).
- **Що повертає:** Числове значення температури у Кельвінах.
- **Приклад використання:**

  ```python
  result = fahrenheit_to_kelvin(77)
  print(result)  # 298.15
  ```
